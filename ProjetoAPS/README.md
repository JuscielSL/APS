📚 Projeto APS — Sistema de Gestão de Clínica Odontológica

Projeto acadêmico desenvolvido para a disciplina de Engenharia de Software do Centro Universitário UDF.

📌 Sobre o Projeto

O Projeto APS tem como finalidade aplicar, na prática, conceitos e princípios fundamentais da Engenharia de Software, envolvendo etapas de análise, planejamento, desenvolvimento, testes e documentação de um sistema.

Durante o desenvolvimento, são aplicadas boas práticas de desenvolvimento de software, buscando proporcionar uma experiência próxima à realidade de um projeto de sistemas.

🎯 Objetivos

O projeto possui como principais objetivos:

Compreender e utilizar os princípios da Engenharia de Software; desenvolver competências para
identificar e definir requisitos; realizar a modelagem e a documentação de sistemas; empregar metodologias de desenvolvimento de software; implementar
e validar uma solução computacional; promover o trabalho em equipe por meio de ferramentas de controle de versão; e integrar os conhecimentos adquiridos ao longo da disciplina.

🔎 Etapas do Desenvolvimento

O desenvolvimento do projeto contempla diferentes etapas da Engenharia de Software:

1. Análise de Requisitos

Levantamento e organização das necessidades que o sistema deverá atender.

2. Modelagem

Criação de modelos e diagramas para representar o funcionamento e a estrutura do sistema.

3. Desenvolvimento

Implementação das funcionalidades planejadas utilizando as tecnologias definidas pela equipe.

4. Testes

Realização de testes para verificar o funcionamento e a qualidade do sistema.

5. Documentação

Registro das decisões, funcionalidades, requisitos e demais informações importantes do projeto.
